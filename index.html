PILIER 01 // OSCP & OSWE

Tests d’Intrusion (Pentest) & Audit de Code

Évaluez la résistance réelle de vos applications et réseaux face à un attaquant déterminé. Nos tests d’intrusion sont réalisés manuellement en boîte noire, boîte grise ou boîte blanche (avec revue complète du code source).

  • Pentest Web, API & SaaS : Exploitation de failles logiques métier, contournement d’authentification/SSO, injections avancées, désérialisation et isolation multi-tenant.
  • Audit de Code Source en Boîte Blanche : Analyse manuelle et assistée (Claude CVP Defense) pour identifier les vulnérabilités zero-day nichées dans votre code applicatif.
  • Pentest Interne & Active Directory : Scénarios « Assumed Breach », Kerberoasting, abus ADCS/GPO, mouvements latéraux et élévation de privilèges.
  • Périmètre Externe & Infrastructures : Audit des surfaces exposées, passerelles VPN, environnements conteneurisés et équipements réseaux.
OWASP WSTG • PTES • OSCP • OSWE

PILIER 03 // ARCHITECTURE

Revue d’Architecture Sécurité & Zero-Trust

Éliminez les failles structurelles dès la phase de conception ou lors de refontes majeures. Nous auditons vos schémas directeurs, flux réseaux et modèles d’authentification pour garantir une défense en profondeur.

  • Architecture Zero-Trust & Segmentation : Conception de micro-segmentation réseau, cloisonnement IT/OT/Cloud, revue des matrices de flux et pare-feux.
  • Threat Modeling (STRIDE) : Modélisation des menaces sur vos architectures logicielles, microservices, API critiques et flux de données sensibles.
  • Identité, SSO & Moindre Privilège (IAM / PAM) : Sécurisation des fédérations d’identités (OIDC, SAML, OAuth2), gestion des accès à privilèges et chiffrement KMS/HSM.
  • Sécurisation des Architectures IA & LLM : Audit des intégrations RAG/LLM, cloisonnement des données et protection contre les injections de prompts (Claude CVP Defense).
NIST 800-207 • STRIDE • ZERO-TRUST
PILIER 04 // AZURE & AWS

DevSecOps & Sécurité Cloud (Azure / AWS)

Industrialisez la sécurité au sein de vos cycles de développement et durcissez vos environnements Cloud Microsoft Azure et Amazon Web Services sans ralentir vos mises en production.

  • Sécurisation des Pipelines CI/CD : Intégration de contrôles automatisés (SAST, DAST, SCA, détection de secrets, SBOM) sur GitHub Actions, GitLab CI et Azure DevOps.
  • Sécurité Microsoft Azure : Audit et durcissement Entra ID (Azure AD), politiques RBAC/PIM, Azure Key Vault, NSG/Private Links et Defender for Cloud.
  • Sécurité Amazon Web Services (AWS) : Revue d’architecture multi-comptes AWS Organizations, SCP, rôles IAM moindre privilège, VPC, KMS, GuardDuty et Security Hub.
  • Kubernetes (AKS / EKS) & Infrastructure-as-Code : Durcissement des clusters conteneurisés, sécurité des images Docker et revue de code Terraform, Bicep et CloudFormation.
